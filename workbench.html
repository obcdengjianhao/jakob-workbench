工作台靠 GitHub Gist 在电脑和手机之间同步。Token 只保存在这台设备的浏览器里，不会写进源码。

如何生成 Token
  1. 打开 GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. 只勾选 Gists: Read and write 这一项权限，不要给仓库权限
  3. 生成后复制，粘贴到上面输入框
